REFERENCES FOLDER
=================

You do NOT need to put anything in this folder to make the template work.

All references live in a single file at the top level of the project:

    bibliography.bib

That file already contains commented examples for a journal article, a
conference paper and a book. Add your own entries there and cite them with
\cite{key}.

WHAT THIS FOLDER IS FOR
-----------------------
Keep your supporting material here so it does not clutter the project:

  * PDFs of the papers you cite (helpful, but do NOT ship them with your
    submission - they are copyrighted)
  * exported .bib files from IEEE Xplore, Scopus or Google Scholar before
    you merge them into bibliography.bib
  * a Mendeley/Zotero export

IEEE FORMAT
-----------
The EEE manual requires the IEEE reference format. It is applied
automatically by the IEEEtran bibliography style set in Thesis_Book.tex - you never
type the formatting by hand. Your job is only to enter correct author names,
titles, volume/issue numbers, page ranges and years.

References are numbered in the order in which they are first cited in the
text, and only cited works appear in the printed list.
