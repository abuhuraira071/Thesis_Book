ASSETS FOLDER
=============

This folder holds the university branding used on the cover page and on the
two certificate pages.

    ruet_logo_color.png   used on the cover page
    ruet_logo_bw.png      used on the certificate pages

>>> IMPORTANT <<<
The two files currently in this folder are PLACEHOLDERS. They are clearly
marked as such so that nobody submits a thesis with them by mistake.

BEFORE YOU SUBMIT, REPLACE BOTH FILES with the official RUET logo:
  * take it from the official EEE 4000 manual PDF, from the RUET website,
    or from the Department office;
  * keep the same two file names, so nothing else has to change; or
  * use different names and update \ruetlogocolor and \ruetlogobw in
    config.tex.

A vector PDF logo gives the best print quality. If you use a raster image,
use at least 300 dpi and a square, transparent or white background.

If a logo file is missing, the template still compiles and prints a visible
boxed reminder in its place instead of failing.
